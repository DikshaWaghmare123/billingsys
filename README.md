# Ronny's Billing App

A static HTML/CSS/JS billing app for local use and GitHub Pages deployment.

## Deployable structure

- Root files for local use
- docs/ folder for GitHub Pages

## Files

- `ronnys-billing-offline.html` — app entry point for local use
- `docs/index.html` — GitHub Pages entry point
- `styles.css` — styling
- `script.js` — billing logic
- `bg1.jpg` — background image

## Local run

Open the HTML file directly in a browser, or serve the folder via a local web server.

## GitHub Pages

Set the Pages source to the `docs` folder if using a repository-based deployment.
